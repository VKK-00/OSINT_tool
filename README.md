# osintkit

Модульний OSINT-тулкіт з фокусом на дослідницькі цілі по **Україні та РФ**: соцмережі, телефонія, телеграм-канали, домени, геолокація та архівування. Python 3.10+, без обов'язкових API-ключів.

> ⚠️ Призначено лише для легітимних досліджень: журналістика розслідувань, верифікація інформації, академічний аналіз. Не для переслідування, спаму чи порушення закону.

## Веб-інтерфейс

```bash
pip install -e ".[web]"
osintkit-web          # → http://127.0.0.1:8765
```

Одна сторінка (vanilla JS, темна тема): вибір модулів чекбоксами, прогрес скану в реальному часі, картки знахідок з рівнями довіри, історія звітів з переглядом старих результатів. Бекенд — FastAPI, звіти пишуться у `out/` як і в CLI.

## Швидкий старт

```bash
pip install -e .
osintkit scan -m all "ivan_petrov"        # все, що підходить під таргет
osintkit scan -m phone "+380501234567"    # телефон: країна/оператор/регіон
osintkit scan -m tg "some_channel"        # публічний телеграм-канал
osintkit scan -m net "example.gov.ua"     # DNS + CT-логи + RDAP
osintkit scan -m email "someone@gmail.com"
osintkit scan -m archive "https://..."    # wayback: снапшот + Save-Page-Now
osintkit scan -m geo "50.45,30.52;180;2.5" # оцінка часу зйомки за тінню
osintkit variants "ivan_petrov"           # кириличні/латинські варіанти ніка
```

Кожен `scan` пише JSON-звіт у `out/`.

## Аналіз: що вже є на GitHub по OSINT (UA/RF)

### Колекції та фреймворки
| Проєкт | Що вміє | Чого не вистачає |
|---|---|---|
| `cipher387/osint_stuff_tool_collection` | найповніша кураторська колекція інструментів | це список, не тул |
| `sinwindie/OSINT` | шпаргалки по платформах | статичний довідник |
| `smicallef/spiderfoot` | сотні джерел, граф зв'язків | важкий, генеричний, слабкий фокус на СНД-платформах |
| `opensanctions/opensanctions` | санкційні/кримінальні списки (OFAC, ЄС, PeP) | потребує інтеграції у пайплайн |

### Пошук осіб / юзернеймів
| Проєкт | Сильне | Слабке для нас |
|---|---|---|
| `sherlock-project/sherlock` | ~400 сайтів, швидкий | майже немає VK/OK/Habr/DTF |
| `soxoj/maigret` | найкраща евристика підтвердження профілю | те саме: СНД-платформи покриті слабко |
| `p0nch0d3v/blackbird` | швидкий, простий | без транслітерації ніків |

### Email / телефон
- `mxrch/GHunt` — OSINT по Google-акаунтах (топ, але вузький).
- `megadose/holehe` — перевірка реєстрації email на ~120 сервісах.
- `sundowndev/phoneinfoga` — номери: країна/оператор/носії; метадані по РФ-DEF-кодах мінімальні.

### Телеграм (ключовий канал для UA/RF)
- `tgscan-dev/tgscan` — пошук TG-акаунта за номером/юзернеймом; закриває нішу, але без архівування контенту каналів.
- Загалом: майже ніхто не робить **моніторинг + архівування** каналів у одному тулі.

### Конфлікт-моніторинг / верифікація
- `bellingcat/auto-archiver` — архівування медіа з посилань (найкраще в класі).
- `bellingcat/tiktok-hashtag-analysis` — аналіз TikTok-хештегів.
- Bellingcat timemaps — інтерактивні мапи подій (дані, не тул).
- `archivebox/archivebox` — самохостинг-архів, важкуватий для швидких перевірок.

### Висновок (ніша для osintkit)
1. **СНД-платформи в першому класі**: VK, OK, Telegram, Habr, DTF у username-скані + транслітерація ніків (кирилиця↔латиниця) — цього немає ні в sherlock, ні в maigret.
2. **Телефонія UA/RF**: офлайн-метадані (регіон/оператор) без ключів.
3. **Telegram**: публічні канали без API-ключа + збереження постів у звіт.
4. **Archive-first**: перевірка і тригер Wayback у кожному скані.
5. **Гео-верифікація**: оцінка часу зйомки за тінню + лінки на Yandex/OSM/Mapillary/SunCalc.
6. **Легкий звіт**: один JSON на таргет, без БД і сервісів.

Див. [docs/ROADMAP.md](docs/ROADMAP.md) — куди рухатись далі (opensanctions-інтеграція, локальний індекс витоків, телеграм-моніторинг, веб-UI).

## Структура
```
osintkit/           # пакет
  core.py           # Finding/ModuleResult, HTTP-клієнт, транслітерація
  modules/          # username, phone, email, net, tg, archive, geo
  output.py         # консоль (rich) + JSON-звіт
docs/ROADMAP.md
config.example.toml # опціональні API-ключі
```

## Етика
Тул не надає функцій масового спаму чи атак ("бомбери" тощо) — це поза межами OSINT і поза межами цього проєкту. OSINT = збір **відкритих** даних.
